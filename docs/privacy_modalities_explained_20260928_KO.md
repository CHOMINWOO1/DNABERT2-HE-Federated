# 이미지·텍스트·DNA 복원율 비교에서 맞춰야 할 조건

2026-09-28. 실험 진행 중 제기된 질문에 대한 문헌 기반 해설이다. 현재 후속 실험의 수치를 대신하지 않는다.

이미지가 본질적으로 복원 가능하고 텍스트·DNA는 본질적으로 복원 불가능하다는 구분은 성립하지 않는다. 공격자가 받는 정보, 학습 목표, 공개 보조자료와 성공 기준을 맞춰 비교해야 한다.

## 1. 공개되는 정보와 누출 경로

| 공격자가 받는 것 | 복구하려는 정보 | 이번 최종 가중치 실험과의 관계 |
|---|---|---|
| 특정 배치의 gradient 또는 개별 업데이트 | 그 배치의 학습 입력 | 추가 학습 중 정보가 필요함 |
| 특정 서열의 토큰별 embedding | 해당 embedding을 만든 입력 | 입력별 표현이 필요하며, 입력이 학습 표본일 필요는 없음 |
| 전체 학습 후 가중치 | 학습 데이터의 흔적 또는 숨긴 속성 | 이번 실험의 조건 |

[Geiping et al., Inverting Gradients](https://arxiv.org/abs/2003.14053)는 공유 gradient에서 이미지를 복구하는 연구다. 이를 최종 분류 가중치만 사용하는 DNA 공격과 직접 비교하면 정보 조건이 섞인다.

[DAGER, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/9ff1577a1f8308df1ccea6b4f64a103f-Paper-Conference.pdf)는 관찰한 self-attention gradient와 이산 어휘 구조를 이용해 텍스트를 복구한다. 이산성은 기존 연속 최적화에는 어려움이 될 수 있지만, 적절한 공격에서는 후보 검증에 도움이 될 수도 있다. 이 논문의 성능을 최종 가중치만 받는 조건에 그대로 적용할 수는 없다.

[How Private Are DNA Embeddings?](https://arxiv.org/html/2603.06950v1)는 해당 입력의 token별 embedding이 제공된 조건에서 100 bp DNABERT-2 서열 약 80%의 완전 일치를 보고한다(§V-B). 같은 논문에서도 mean pooling한 표현의 복구는 훨씬 어려웠다. DNA라는 자료형 자체보다 표현에 남아 있는 위치별 정보가 중요하다는 사례다. 이 결과를 개별 embedding 없이 최종 가중치만 주어진 현재 실험의 기대 복구율로 사용하지 않는다.

## 2. 분류 label과 학습 목표

[The Secret Revealer / GMI, CVPR 2020](https://arxiv.org/pdf/1911.07135)는 최종 얼굴 분류기 가중치와 공개 자료로 학습한 생성기를 사용한다. §3.1의 얼굴 분류 label은 사람의 identity이며, 해당 identity에 대응하는 얼굴 특징을 복원하는 목표다. 공개 얼굴 분포에서 얻은 생성 prior가 후보 공간을 제한한다.

우리 H3K4me3 모델은 양성/음성 분류기다. 동일한 분류 결과와 부합하는 서열이 많기 때문에, 높은 클래스 확률을 주는 서열과 실제 학습 원문을 구분해야 한다. 이 설명은 학습 목표의 차이에 대한 추론이며, 분류 가중치에 원문 정보가 전혀 없다는 주장이 아니다.

분류 학습은 원문 생성 능력을 유지하도록 직접 최적화하지 않는다. [분류용 BERT 개체명 추출 연구](https://arxiv.org/pdf/2212.03749)는 분류 head 대신 원 MLM head를 붙였지만 미세조정 데이터 고유 개체명 추출이 일관되게 늘지 않은 사례다. 현재 실험의 encoder/head 불일치 가설은 이 선례와 부합하나, 별도 실험 없이 확정할 수 없다.

텍스트는 gradient가 있어야만 복구되는 것도 아니다. [Carlini et al., USENIX Security 2021](https://www.usenix.org/conference/usenixsecurity21/presentation/carlini-extracting)은 GPT-2에 질의하여 학습 데이터의 원문 서열 수백 개를 추출한 사례를 보고한다. 자연어를 생성하도록 학습된 모델과 기능 분류용으로 미세조정한 DNA encoder를 같은 복원 조건으로 취급하지 않는다.

## 3. 시각적 유사성, 속성 복원, 원문 일치

같은 사람처럼 인식되는 얼굴, 픽셀 유사도가 높은 이미지, 단어의 일부 회수, 염기별 정확도, 숨긴 구간의 완전 일치는 서로 다른 지표다. 이미지에서 정확한 원본 복구가 가능한 연구도 있지만, 시각적으로 성공한 예제만으로 모든 픽셀이 같다고 볼 수는 없다.

위치별 오류가 독립이라는 단순 예에서 염기별 정확도가 99%여도 100 bp 전체 일치 확률은 0.99^100 ≈ 36.6%다. 실제 DNA의 위치별 오류가 독립이라고 가정하는 분석은 아니며, 지표 차이를 보여주는 계산이다.

[Text Revealer](https://arxiv.org/pdf/2209.10505)의 Recovery Rate는 필터링한 토큰의 회수 비율이다. 이를 문장 전체 exact match와 같은 복구율로 읽지 않는다. 우리의 주 지표는 숨긴 부분 전체 exact match이며, 이미 알려준 주변 문맥은 분모와 정답 수에 포함하지 않는다.

## 4. 이번 후속 실험이 판별할 수 있는 것

- 같은 모델에서 전수 후보 탐색/beam 및 공개자료 head 보정으로 기존 공격의 제한을 점검한다.
- 동일한 학습 궤적의 1/5/10/20 epoch에 같은 공격을 적용해 학습량 효과를 본다.
- 학습 표본과 비학습 표본의 변화를 함께 비교해 일반적인 DNA 예측 개선과 학습 표본의 추가 이점을 구분하려 한다.
- 이 실험은 이미지와 DNA의 자료형 효과를 직접 비교하는 실험이 아니다. 그 주장을 하려면 정보 조건·모델 목표·보조자료·예산·성공 지표를 맞춘 별도 설계가 필요하다.
- 특정 표본의 암기를 인과적으로 입증하려면 포함/제외 또는 대체 재학습 대조가 더 필요하다. reference genome 조회나 개인의 희귀 변이 복구도 현재 평가 범위 밖이다.

최종 가중치에서의 암기 누출, 학습 중 gradient 누출, 공유 embedding에서의 입력 누출을 연구 질문부터 분리해야 한다. 통신 암호화와 최종 공개 모델의 프라이버시 역시 각각 평가해야 한다.
